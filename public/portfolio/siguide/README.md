# SiGuide reference media

These are WebP encodings of the existing public SiGuide project images, at their original dimensions. No generated detail or raster enlargement was applied.

- `device-reference.webp`: original device photograph, 1212 × 874. Source: https://uilvozcryifnpldfpwiz.supabase.co/storage/v1/object/public/project_images/4jn2ard683w.png
- `opening-reference.webp`: opening-screen reference, 2912 × 2184. Source: https://uilvozcryifnpldfpwiz.supabase.co/storage/v1/object/public/project_images/zf5cy7p6aqh.png
- `tour-reference.webp`: tour-screen reference, 2912 × 2184. Source: https://uilvozcryifnpldfpwiz.supabase.co/storage/v1/object/public/project_images/wgovb0jy5f.png

- `object-reference.webp`: individual-object screen reference, 2912 × 2184. Source: https://uilvozcryifnpldfpwiz.supabase.co/storage/v1/object/public/project_images/sshrkxg326.png

The SiGuide device by WIVID is reconstructed in Three.js. Screen typography, icons, navigation, and the tour map are redrawn in Canvas; the postage collage, blue envelope, and stagecoach photograph are cropped from these archival references. The tour map is a visual reconstruction of the historical interface. The original screenshot gallery remains available below the animated hero, and the hero links to the original device photograph.
