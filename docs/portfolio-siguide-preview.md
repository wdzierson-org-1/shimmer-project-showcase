# SiGuide device preview

Local preview: http://127.0.0.1:8083/#case=7b4a9961-a088-46f4-bc88-8f0d64589227

The Smithsonian project hero now reconstructs the original charcoal SiGuide handheld in Three.js, by WIVID. The second pass uses the prefiltered studio environment from the earlier homepage sculpture, smoother and wider molded bevels, distinct rubber and satin plastic materials, clearcoat, physical speaker perforations with recessed wells, a deeper protective bumper, button sockets, and reflective cover glass. A soft ambient shadow complements the directional shadow. The cyan device badge and embossed manufacturer mark now read SiGuide and WIVID. Native screen text, icons, navigation, and an isometric tour map replace the low-resolution UI within the old device photograph. Archival photographs remain within the reconstructed interface.

A 24-second sequence draws the schematic, materializes and turns the device, wakes the display, selects Tours, opens a tour synopsis, traces its museum route, then opens the original Concord-style Stagecoach model, 1851, object screen. The object photograph gently settles into place before playback stops. Pause, replay, and direct Home / Tour / Map / Object controls are available. Reduced-motion preferences show the completed Home view with manual screen selection. The animation pauses when offscreen or when the tab is hidden; resources are released on unmount. If WebGL is unavailable, the original device photograph remains visible.

Only the Smithsonian case loads the new component. Project title, description, contribution, and gallery captions normalize the device name to SiGuide in the local interface; the public source records and original screenshots remain historical references. Its existing screen gallery follows the hero; the replaced device photograph is available through a direct reference link. No runtime dependencies or database changes were added. The Three.js dependency is shared with the existing homepage film.

Validation: TypeScript and focused ESLint pass. Six sequence / geometry tests and three existing routing tests pass. Tests cover screen visibility through the bezel, manual and reduced-motion views, deterministic seeking, completion without looping, and finite geometry within mobile and desktop camera frames. The four actual Canvas screen compositions, 121 sampled timeline frames, and schematic/device geometry were rendered with a temporary native Canvas tool and inspected; this verified the object photo crop, corrected device badge, and screen transitions. The local page, component, and object reference asset respond with HTTP 200. Production build passes with the existing large-chunk and Browserslist notices.
